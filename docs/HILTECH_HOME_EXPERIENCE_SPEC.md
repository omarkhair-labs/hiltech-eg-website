## H01 — Engineered Signal

Purpose:
- establish the creative thesis immediately
- create the strongest cinematic moment
- position HILTECH as an engineered infrastructure company, not a generic IT vendor

Primary H01 statement:
**EVERY SIGNAL NEEDS A PHYSICAL PATH.**

Internal lifecycle:
**BUILD → ROUTE → TEST → PROVE**

The lifecycle is a state/motion rail, not the giant hero headline.

Visual behavior:
- dormant physical infrastructure environment
- one signal activates through a fiber/termination world
- typography and route line share the same spatial composition
- signal reveals the physical path
- camera begins to disclose system scale

Motion:
- authored clip/width/track typography reveal rather than generic fade-up
- signal pulse
- path trace crossing the composition
- text locks into final structure as the route becomes active
- first scroll carries the signal into H02 instead of fading the page out

Recommended implementation:
- Three.js/WebGL master scene
- GSAP/ScrollTrigger
- optional pre-rendered CG support for non-interactive atmosphere

## H05 — Build → Route → Test → Prove

Purpose:
- signature HILTECH lifecycle
- center of the homepage story
- show one physical system changing state instead of presenting four disconnected service panels

Implementation contract:
- one native-sticky viewport
- one GSAP scrubbed timeline
- SVG process field rather than another WebGL scene
- MotionPathPlugin is justified only for the route signal traveling along the actual path
- no fabricated measurements or performance metrics

Sequence:

### BUILD
Terminations, racks, endpoints, and containment assemble into one installed structure.

### ROUTE
The installed structure becomes a continuous physical path from source to destination.

### TEST
The same path moves into an illustrative measurement state with trace, scan, remediation/retest language.

### PROVE
The system resolves into a documented handover-ready state and the motion settles.

Rule:
Keep it concentrated. Do not stretch this into an unnecessarily long pinned sequence. The sequence may occupy scroll distance, but it should read as one transformation, not four slides.

## Copy direction

Avoid generic corporate claims.

Prefer short, technical, declarative copy.

Brand voice:
- Precise
- Kinetic
- Engineered
- Assured

Machine/system voice:
- mono labels
- measurements
- port/link/trace/state metadata

Examples of system-style labels:
- PORT 24 / ACTIVE
- LINK / VERIFIED
- OTDR TRACE / PASS

Do not use fictional telemetry as company proof.
