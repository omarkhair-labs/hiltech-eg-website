## Why the workflow changed

Two user corrections materially improved this project.

### Home reset

The first live H01-H03 implementation followed static AI concept boards too literally. Typography/composition became generic premium-tech and the screenshots were starting to act like the brief.

The correction produced the core rule:

Code is not supposed to reproduce screenshots. Code must reproduce the creative system.

The final Home hero became:

EVERY SIGNAL NEEDS A PHYSICAL PATH.

BUILD → ROUTE → TEST → PROVE remains the internal lifecycle/motion system instead of a generic giant slogan.

### Products reset

The first Product research was too focused on functional technical catalogs such as CommScope, Schneider, Panduit and DigiKey-style finding/filter/RFQ patterns.

Those references are useful for functionality and IA, but they are not the creative art-direction references that made HILTECH strong.

The Product lane was reopened after identifying that the core catalog still looked like a conventional card grid wearing a HILTECH skin.

The new Product thesis is:

HILTECH Products = an explorable physical infrastructure library + procurement system.

Product journey:

SYSTEM → FAMILY → REFERENCE → PROJECT FIT → RFQ
